# 🌿 Youth & Community Care (YCC) Charitable Trust

A modern, responsive, full-featured web application for **Youth & Community Care (YCC) Charitable Trust** built with HTML5, CSS3, JavaScript (ES Modules), Vite, and LocalStorage state engine.

![YCC Trust Banner](public/assets/images/hero.jpg)

---

## ✨ Features

- 🎨 **Modern Design System**: Built with an emerald green (`#064e3b`, `#047857`) and warm gold (`#f59e0b`) palette, Google Fonts ('Outfit' & 'Plus Jakarta Sans'), smooth micro-interactions, dark/light theme toggle, and glassmorphic cards.
- 📱 **Fully Responsive**: Mobile-first architecture tested across mobile, tablet, and desktop viewports.
- 💳 **Interactive UPI & Card Donation Gateway**: Multi-step checkout supporting preset amounts (₹500, ₹1000, ₹2500, ₹5000, Custom), campaign binding, PAN tax number input, live UPI QR Code simulator (`ycctrust@upi`), and Credit/Debit Card 3D Secure OTP verification.
- 📜 **80G Tax Exemption Certificate Generator**: Instant official receipt generation complete with YCC Trust Seal, 80G/12A Reg numbers, donor details, PAN card, QR verification, and 1-click **Print / Download PDF** functionality.
- 📊 **Admin CMS & Financial Funds Dashboard**:
  - Live revenue stats & quarterly target meters.
  - Interactive **Funds Breakdown by Campaign & Gateway Channel**.
  - **Donation Transaction Logs** & 1-click **CSV Export**.
  - Campaign CMS (Add/Edit/Delete projects).
  - Events & Workshop CMS.
  - Media Gallery CMS.
  - Volunteer Application Review & Approval workflow.
- 👤 **Donor Portal**: User registration, login, total contribution stats, tax savings calculator, donation history table, and receipt re-downloading.
- 🖼️ **Media Gallery & Lightbox**: Filterable photos and videos with full-screen Lightbox.
- 🤝 **Volunteer Army Portal**: Skill-based application form with real-time status updates.

---

## 🛠️ Tech Stack

- **Core**: HTML5, Vanilla JavaScript (ES Modules), Vite
- **Styling**: Modern CSS3 (CSS Variables, Flexbox, Grid, Glassmorphism)
- **Icons**: Lucide Icons
- **Effects**: Canvas Confetti
- **Storage**: LocalStorage State Engine with initial seed data

## 🚀 Quick Start Guide

### Option 1: Double-Click Local Server (No Setup Required)
1. Open the project folder `c:\Users\mi\OneDrive\Desktop\YCC Website\`.
2. Double-click `Start-Local-Server.bat`.
3. Open your browser at **[http://localhost:3000/](http://localhost:3000/)**.

### Option 2: Run via NPM / Vite
```bash
# Clone the repository
git clone https://github.com/<YOUR_USERNAME>/ycc-trust.git

# Navigate into directory
cd ycc-trust

# Install dependencies
npm install

# Run dev server
npm run dev
```
